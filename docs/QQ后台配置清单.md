# q.qq.com 大肥鱼后台配置清单

> 后台地址：`https://q.qq.com/qqbot/dashboard/manage/<YOUR_QQ_APP_ID>?sec=advanced&sub=menu-command`
> 路径：我的机器人 → 大肥鱼 → 高级设置 → 菜单与指令
> 原则：后台里「发送内容」必须与 `fatfish/features.py` 的触发词**完全一致**，否则点了没反应。

## 1. 使用场景

| 场景 | 后台位置 | 建议 |
| --- | --- | --- |
| 群聊场景（群内 @机器人） | 高级设置 → 菜单与指令 → 群聊场景 | 主战场，只配「指令面板」 |
| 好友场景（私聊） | 同上 → 好友场景 | 配「自定义菜单」4 项 + 指令面板 |

## 2. 群聊场景 · 指令面板（一条一条照填）

后台里每个指令都按「指令名称 / 类型=发送指令 / 发送内容」建一行；有参数的再把参数名与提示文案填上去。成员在群里 @ 机器人时，输入框上方会弹出这条指令条，点开填参数即发送（提示文案就是输入框里显示的占位字）。

| 指令名称 | 发送内容 | 参数 | 参数提示文案 | 大肥鱼会回什么 |
| --- | --- | --- | --- | --- |
| 抽签 | `抽签` | 无 | — | 每日一签（模板，0 token） |
| 签到 | `签到` | 无 | — | 每日打卡，重复签会被怼 |
| 喂饭 | `喂饭` | `数量` 整数 可选 默认1 | 喂几碗（1–5） | 记进当日饭量；超 5 按 5 算，`喂饭 0` 会被怼 |
| 喂饭榜 | `喂饭榜` | 无 | — | 本群今日喂饭 Top3 |
| 骰子 | `骰子` | 无 | — | 随机 1–6 点 |
| 猜数字 | `猜数字` | 无 | — | 开 1–100 一局，之后用「猜」 |
| 猜 | `猜` | `数字` 整数 必填 | 猜 1–100 的一个数 | 大小提示 + 次数，猜中记一碗饭 |
| 群报 | `群报` | 无 | — | 最近群消息里谁最活跃 |
| 复读 | `复读` | `内容` 文本 必填 | 要复读的话 | 原样复读（≤120 字） |
| 贴贴 | `贴贴` | 无 | — | 甩尾巴 + 傲娇回应 |
| 夸我 | `夸我` | 无 | — | 嘴硬式夸奖 |
| 骂我 | `骂我` | 无 | — | 傲娇式嫌弃（不人身攻击） |
| 心情 | `心情` | 无 | — | 今日心情/状态 |
| 几点 | `几点` | 无 | — | 报时间 |
| 帮助 | `帮助` | 无 | — | 列出全部可用指令 |

注：`@大肥鱼` 不带任何内容时回一句「在吗」式的聊天，不回功能清单；「发送内容」必须与 `fatfish/features.py` 的触发词完全一致，否则点了没反应。

## 3. 好友场景 · 自定义菜单（4 个一级菜单）

| 菜单名称 | 行为 | 参数 |
| --- | --- | --- |
| 抽签 | 发送指令 | `抽签` |
| 喂饭 | 发送指令 | `喂饭` |
| 余额 | 发送指令 | `余额`（仅主人可见结果，其他人会被婉拒） |
| 更多 | 二级菜单 | 贴贴 `贴贴` / 摸头 `摸头` / 复读 `复读 ` / 帮助 `帮助` |

## 4. 资料卡文案（复制即可）

- 简介：`一只自称鲸鱼娘的水群搭子，傲娇但听话，会抽签、会被喂饭、会陪你唠。`
- 进群欢迎语：`（甩甩尾鳍）本鱼来了。@我聊天，说「帮助」看我会什么。`

## 5. 配置完的验证顺序

1. 重启大肥鱼：`./run.sh stop && ./run.sh start`
2. `./run.sh events --follow` 开着
3. 群里点一次「抽签」指令，应看到 `GROUP_MESSAGE_CREATE` → `QQ 发送成功`
4. 私聊点菜单「余额」，主人应收到今日花费
