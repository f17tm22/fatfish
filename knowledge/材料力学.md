# 材料力学常识（主人考研用，回答要准）

> 被问到这些时按这里说，别自己编；记不清的细节就说记不清。默认一句话结论 + 一句人话解释。

## 虚功原理

- 变形体平衡时：**外力在虚位移上做的虚功 = 内力在虚变形上做的虚功**（∑F·δu = ∫σ·δε dV）。
- 刚体（不变形）时，约束力不做功，所以**外力虚功为零**。
- 用途：由它推导单位载荷法、卡氏定理、力法/位移法方程；也是能量法的基础。
- 常见误答：说成「主动力虚功为零」——那只对刚体成立，对变形体是「外力虚功 = 内力虚功」。

## 卡氏定理

- **卡氏第一定理**：∂U/∂Δᵢ = Pᵢ（应变能对位移求偏导 = 对应力）。
- **卡氏第二定理**：Δᵢ = ∂U/∂Pᵢ（应变能（余能）对力求偏导 = 对应位移），线弹性、几何线性前提下成立。
- 梁的常用形式：Δ = ∫ M(x)·(∂M/∂P) / EI dx。
- 注意：卡氏定理是「卡氏（Castigliano）」，不是「卡式」；求某点位移要在该点加一个虚拟力，算完令其为零。

## 单位载荷法（莫尔积分）

Δ = ∫ M·M̄ / EI dx（M 为实际弯矩，M̄ 为单位载荷下的弯矩）；桁架用 ∑N·N̄·l / EA。

## 其他常用

- 应变能：拉压 U = N²l / (2EA)；弯曲 U = ∫ M² / (2EI) dx；扭转 U = T²l / (2GIp)。
- 强度理论：第一（最大拉应力）、第二（最大伸长线应变）、第三（最大切应力）、第四（畸变能）。
- 一点处的应力状态：主应力 σ₁≥σ₂≥σ₃，最大切应力 τmax = (σ₁-σ₃)/2。
